# Solos review assets

Small public images used in Solos code review reports on GitHub, in GitHub's notification e-mail and in the Solos
app. GitHub shows images in a pull request only from a public web address, so they live here and are served by
GitHub Pages at `https://solosapp.github.io/review-assets/icons/<name>.svg`.

| File | Meaning | Colour |
|---|---|---|
| `icons/critical.svg` | Critical finding | `#9B1C1C` |
| `icons/high.svg` | High finding | `#D9473F` |
| `icons/medium.svg` | Medium finding | `#D18A1A` |
| `icons/low.svg` | Low finding | `#E6C36A` |
| `icons/manual.svg` | Needs a manual check | `#7B8794` ring |

Each is a 10 px SVG that carries its own size. Keep the names: published reviews link to them.
